# Specifications

This directory contains stable data/interface specifications used by OME.

Specifications differ from:

- requirements, which define what behavior is needed;
- ADRs, which record why architecture decisions were made;
- domain documentation, which defines meaning;
- research, which is informative and not automatically normative.

A specification may define a file/profile contract, schema or other interoperability boundary.


## Current accepted specifications

- `ome-csv-profile-v0.1.md` — controlled CSV interchange profile;
- `lap-comparison-v0.1.md` — distance-aligned deterministic base comparison;
- `lap-continuous-overlay-v0.1.md` — continuous supporting evidence;
- `lap-discrete-gear-overlay-v0.1.md` — discrete gear sampling;
- `brake-semantic-compatibility-v0.1.md` — safe brake semantic matching;
- `lap-delta-observations-v0.1.md` — deterministic gain/loss observation regions;
- `lap-comparison-report-v0.1.md` — application-level report bundle;
- `local-comparison-report-http-api-v0.1.md` — local HTTP transport;
- `mvp-comparison-preparation-v0.1.md` — source-evidence to report-request preparation workflow.
