# Validated Domain Knowledge

This directory contains motorsport engineering knowledge that OME has deliberately adopted for product use.

It is distinct from `docs/research/`.

Research may contain valuable material, hypotheses and external sources. Content should only move here after review and after its intended use in OME is understood.

## Suggested module structure

- Concept
- Physical meaning
- Relevant measurements
- Derived quantities
- Engineering questions
- Possible observations
- Possible hypotheses
- Required evidence
- Limitations
- Common misinterpretations
- Source / validation status
- OME explanation pattern

Avoid universal setup recipes. Prefer physical relationships, observable variables, competing hypotheses and evidence that can distinguish them.
