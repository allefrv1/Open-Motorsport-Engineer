# External References

This directory catalogs external material that informs OME.

External references are not automatically project rules.

For each important reference, record:

- title;
- owner/publisher;
- URL;
- date verified;
- what OME relies on it for;
- whether the content is normative, informative or feasibility evidence.

Do not copy copyrighted source material into the repository unless redistribution is clearly permitted.

Durable project decisions derived from a reference belong in requirements, ADRs, specs or domain documentation.
