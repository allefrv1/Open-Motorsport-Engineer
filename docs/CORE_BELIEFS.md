# OME Core Beliefs

Status: **Accepted**

These are durable engineering principles for both humans and coding agents.

## 1. Evidence before explanation

OME preserves and validates evidence before producing interpretation.

## 2. Unknown is a valid state

Missing or ambiguous telemetry must remain explicit. The system must not invent certainty.

## 3. Source data is evidence

Original telemetry identity, units, timing and provenance must remain recoverable after every transformation.

## 4. Deterministic before generative

Critical calculations belong in deterministic engineering logic. AI operates on structured evidence above that layer.

## 5. Domain before infrastructure

Architecture should represent motorsport engineering concepts. Frameworks, storage engines and vendors must not define the domain.

## 6. Smallest correct system

Complexity requires a documented reason. Prefer local, modular and reversible choices until evidence demands more.

## 7. Repository knowledge is operational knowledge

Important decisions must live in versioned, discoverable repository artifacts rather than only in chats or human memory.

## 8. Rules that matter should become checks

Documentation is necessary but insufficient. Once implementation begins, important invariants should be encoded in tests, linters, schemas or structural checks where practical.

## 9. Plans are temporary; decisions are durable

Execution plans track work. Requirements, ADRs, specs and domain documents retain durable decisions.

## 10. Human judgment stays explicit

Agents may execute broadly inside established boundaries. Product intent, irreversible trade-offs and uncertain engineering conclusions remain visible to human maintainers.
