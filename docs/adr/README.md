# Architecture Decision Records

This directory records architecture decisions with meaningful long-term consequences.

ADRs explain why a decision was made, not merely what code exists.

## Naming

Use `NNNN-short-decision-title.md`.

## Status

- Proposed
- Accepted
- Superseded
- Deprecated
- Rejected

Codex may propose an ADR, but it must not mark a major decision as Accepted without maintainer approval.

See `0000-template.md`.
